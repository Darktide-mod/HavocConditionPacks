# HavocConditionPacks 1.0.0-r2

## English

Documentation revision. Mod version 1.0.0, Frenzied assault 2.2.1, +20% melee attack/animation speed, and all gameplay and animation files are unchanged.

The repository and installation package now include full English and Chinese instructions for purpose, installation, direct loading, updates, removal and development checks.

- [ConditionPacks source and instructions](https://github.com/Darktide-mod/HavocConditionPacks)
- [HCM source and interfaces](https://github.com/Darktide-mod/HavocConditionManager)
- [HCM downloads](https://github.com/Darktide-mod/HavocConditionManager/releases)

Install HCM 4.5.0 or later, place HavocConditionPacks under `mods`, and load it after HCM. Close Darktide before using the animation installer. HCM reads condition files directly; no DIY extraction is required. See the README for legacy installations and removal.

Download `HavocConditionPacks-1.0.0.zip` below. The automatic Source code archives are not installation packages. The collection includes animation patches and CMD/PowerShell installers; no Nexus approval is claimed.
