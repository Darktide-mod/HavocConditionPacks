# 狂暴攻势：原版红针版
对应 HCM 4.4.7 / 词条包 2.0.0。

全体敌人使用游戏原有的同一个 mutator_stimmed_minion_red 增益，不按枪械、兵种或动作区分。原版近战攻速属性增加 40%，保留 impact_modifier = -2、stagger_duration_multiplier = 0.1、原版攻击许可和红针特效。该硬直时长属性不能解释成敌人自身受到的硬直缩短 90%；保留其原版消费方式。

近战开始时由原版读取攻速属性，通常更早结束行为，并缩短被格挡后的恢复；命中时点及整段挥击动画不再由模组等比提前。原版的最早结束时间和目标方攻击许可仍然有效。移动、枪械、投弹、捕网、扑咬、翻越、出门、受击等按原版处理。

实现只在词条激活时检查一次已有敌人，并在 HCM 的现有生成通知后为新敌人添加增益。使用原版增益模板及原生网络同步；已有任一种原版红针时不重复添加。结束时只移除词条拥有的增益，保留后来改变的攻击许可和其他来源的增益。

移除了动画对象映射、底层内存校验与读取、动画时间步长钩子、AI 动作数据替换、移速修正以及轮询。用于任务结束清理的弱引用集合只记录增益归属，不逐帧遍历。纯原生脚本也不再强制开启 DIY 属性更新或逐帧生成空的属性结果。游戏自身的增益结算、特效与网络同步仍有正常开销。

在大厅更新完整 HCM ZIP，重新加载 HCM，再点击“解压模板DIY词条”更新外部词条，确认狂暴攻势包为 2.0.0，然后开新局。任务中仍保留开局快照。新版 ZIP 不含也不加载原生辅助库；若当前进程已加载旧版辅助库，迁移仅关闭旧钩子，保留已分配的跳板存储直到进程退出，避免仍在退出中的调用访问已释放内存。

禁止医疗及死灵 UI 保持原有实现。只生成发布文件，不写入游戏 mods、AppData 或 Vortex，不上传 Nexus。
