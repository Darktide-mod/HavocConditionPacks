# 狂暴攻势 4.4.4：数值与日志修复

HCM 发布版本 4.4.4；内置狂暴攻势模板包 1.3.0。保留 4.4.3 的敌人增益销毁修复。

## 效果

| 项目 | 本次配置 |
| --- | --- |
| 作用范围 | 全部敌人，包括 Boss；仅本地有游戏逻辑权限的任务 |
| 近战、远程攻速 | 均提高 40% |
| 移动速度 | 特感提高 30%，其余提高 20% |
| 前摇与瞄准 | 支持的时间字段乘 0.5 |
| 再次出手冷却 | 支持的冷却字段乘 0.2 |
| 普通受击硬直 | 恢复等待乘 0.1 |
| 出手许可 | 受影响敌人放开自身许可和目标围攻配额的等待 |

普通近战仍使用原版攻速运算及命中后的最小时间保护，避免将 +40% 重复计算。未读取近战攻速的特殊动作显式缩短周期。射程、视线、目标锁定、伤害和生命值没有在本词条中改动。

两类掷弹兵的六种普通投掷动画和两种快速投掷动画均覆盖：投出手雷、可掉落手雷、特效启动和整套动作的时间同步减半；投掷冷却缩短 80%，包括普通叛军掷弹兵使用原版难度默认冷却的路径。邪教徒普通投掷举例：出手约 2.47 秒 → 1.24 秒，整套动作约 4.17 秒 → 2.08 秒。

“普通受击硬直缩短 90%”直接作用于原版受击动作恢复计时。原版 `stagger_duration_multiplier` 在攻击工具中由攻击者提供，直接把它作为敌人被动数值不足以保证敌人的受击恢复，因此此处没有沿用这一做法。

安装 HCM 4.4.4 后请重启游戏，在「DIY 管理」点击「解压模板DIY词条」，更新外部狂暴攻势包，再开始下一局。该按钮会覆盖全部同名模板并备份旧包；仅替换模组 ZIP 不会自动重写已经解压的模板。
